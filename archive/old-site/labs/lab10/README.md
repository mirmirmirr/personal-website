# zhengm4-lab10

Azure Link: http://zhengm4rpi.eastus.cloudapp.azure.com/iit/

Github: https://github.com/RPI-ITWS/itws1100-zhengm4

This lab was meant to combine what I learned about Atom and RSS feeds with AJAX, creating a page that loads the information from those database-types dynamically. The way the feeds themselves are presented are fairly simple: I kept information about each article inside a card and each of those cards is contained within a grid.
