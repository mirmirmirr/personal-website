I really liked working on this lab because I feel like using JSON, JavaScript, and jQuery on my website makes it cleaner in a way. In the past, I created separate project html files for each lab with their descriptions and a link to the actual lab solution, but through this lab I was able to consolidate everything, making it more more efficienlty. 

Originally, I wanted to mimic what I had on the first version of my projects page but later decided against it. Instead, I created a new design for the Projects layout that I feel fits better with the theme of by site. It contains a horizontal scrolling of each lab/project on the bottom, and whenever a card is clicked, information about that specific lab will toggle on above it. Given more time, I think I would love to write better CSS for the page to have the scrolling container stay in the same place on the page, but I think it works well for now.
