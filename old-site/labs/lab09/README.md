This lab was definately one of the harder labs, but it was also a really fun lab. I thought it was very cool how the database works with the php, javascript, html, and css to create one coehesive and interactive website. I would love to get the chance to play around with these databases another time and see what can happen. 

Within the lab, there are files for the actors table, movies table, and relationships table as well as each of the tables' respective .php files for displaying it on the site. Each of the tables will display within their own tabs with options to add new elements if desired. If the user adds a new element to any table, the SQL database will update accordingly.
